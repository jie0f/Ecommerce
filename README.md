# E-Commerce Site (Frontend)

## 📝 Overview

**E-Commerce Site** is a front-end-only replica of an e-commerce website built using **HTML**, **CSS**, and **JavaScript**. This project simulates the structure and design of a modern online store, showcasing products, a shopping cart, and basic UI interactions like adding products to the cart and viewing the cart details. It's a static site and does not include any back-end functionality.

The goal of this project is to demonstrate front-end web development skills, including responsive design and basic JavaScript functionality, while mimicking the look and feel of a real-world e-commerce site.


## 🚀 Features

- **Product Gallery**: Displays a variety of products with images, names, and prices.
- **Add to Cart**: Allows users to add products to the cart and view their selections.
- **Responsive Design**: The application adjusts to both mobile and desktop screen sizes, ensuring a seamless experience on all devices.
- **Shopping Cart**: Users can view the items they've added to the cart with their details and total price.
- **Simple Checkout Flow**: Simulate the checkout page with a summary of selected items (without actual back-end functionality).
- **Modern UI**: Clean, minimal design for a user-friendly shopping experience.

## 🛠️ Technologies Used

- **HTML**: For structuring the website's content and pages.
- **CSS**: Used for styling the layout and making the site responsive.
- **JavaScript**: Handles the interactive features like adding products to the cart and updating the cart page.
- **Responsive Design**: Ensures the website adapts to both mobile and desktop devices using CSS media queries.
